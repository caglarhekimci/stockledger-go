# ADR 0001: transactional outbox

Reservation state and an outbox event are written in the same PostgreSQL transaction. Publishing directly to Kafka would permit a committed reservation with a lost event, or an event for a rolled-back reservation. Workers atomically lease one event per sequential publish; a lease expires after a crash, failed publication delays the next attempt, and acknowledgement requires the lease token. Network/publish timeouts are bounded below the lease. Delivery is at least once, including a timed-out call that may complete late, and consumers must deduplicate by stable event ID.
